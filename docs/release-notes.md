This release provides an Alibaba Cloud ESS Fleeting provider for prepared Linux
SSH workers, with a static Windows WinRM HTTPS connection path and a separate
Docker Autoscaler configuration. Consult the versioned parity and acceptance
reports for implementation and offline coverage.

Live Alibaba Cloud/GitLab acceptance has not run for this release. There is no
previous live-verified release. OCI package visibility and anonymous Runner
installation must be verified before public distribution is claimed. No claim
of production acceptance or full official capability parity is made.
